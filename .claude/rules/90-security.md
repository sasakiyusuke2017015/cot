# Security & Safety Rules

## 禁止

- `.env` / 認証情報 / 秘密鍵を読む・教材や問題に埋め込む
- 外部ネットワークからスクリプトを無断取得・実行する（CDN URL は文字列として埋めるだけ）
- `ai_edu` 側のファイルを `--apply` の確認手順なしに上書き・削除する
- `ai_edu` の DB / migration / provision / 他スクリプトを勝手に実行する
- `git push` / `git commit` をユーザ承認なしに実行する

## 教材・問題コンテンツの安全

- 個人情報・社外秘・APIキー・実在の社内固有情報を含めない
- 例示データは架空のものにする
- 元資料（`input/raw/`）にない事実を断定で書かない。不足は `TODO:` で残す
- セキュリティ/個人情報/著作権/ハルシネーション/人間による最終確認のテーマを重視する

## ai_edu への書き込み

- 書き込みは `scripts/*.mjs --apply` 経由のみ。手編集での `ai_edu` 直接変更はしない
- `--apply` 前に、書き込み/上書き対象のファイル一覧を提示する
