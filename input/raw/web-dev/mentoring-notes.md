# Web開発の虎の巻 — 元資料（メンタリング方針のやりとりメモ）

新人プログラミング教育についてのやりとりの要点。虎の巻HTML・教材生成の根拠資料。

## 前提条件

- 生徒2人、リモート（離れている前提）
- プログラミングはかじった程度
- Web開発が対象
- 学習時間は1日1時間

## 基本理念

新人教育は「文法を教える」よりも、**自分で調べて・考えて・修正できるエンジニアに育てる**ことが重要。

## 一般的な育成の流れ

### 1. 基礎理解（1〜2週間）

目的: コードが読める状態にする。

- 開発環境構築: VS Code / Git / ターミナル操作
- プログラミング基礎: 変数 / 条件分岐 / 繰り返し / 関数 / 配列 / クラス
- デバッグ方法: エラー文を読む / ログを見る

重要: 「答えを教える」より、**エラー文 → 原因仮説 → 調査 → 修正** の流れを体験させる。

### 2. 小さい成果物を作る（2〜4週間）

目的: 実際の開発感覚をつける。

- 初級: TODOアプリ / 電卓 / CSV集計ツール / 簡単なWeb API
- 中級: ログイン機能 / DB CRUD / ファイルアップロード / 外部API連携

完成度より「**なぜこの設計にしたのか**」を説明できることを重視。

### 3. 実務形式へ移行

目的: チーム開発を経験する。

- Git: branch / commit / pull request / merge
- コードレビューで見るポイント: 命名 / 重複 / 責務分離 / エラー処理 / セキュリティ
- 開発フロー: 仕様確認 → 設計 → 実装 → テスト → レビュー → リリース

### 4. 避けること

- ❌ 最初から大きなシステムを触らせる（全体像が見えず混乱する）
- ❌ 「分からなかったら聞いて」（質問方法が育たない）
  - 代わりに「**30分調べて、分かったこと・試したこと・仮説を持って聞く**」を教える
- ❌ 文法暗記中心（実務では検索・AI・ドキュメントを見る。知識量 → 問題解決能力への移行が重要）

### 5. 伸びる新人の特徴

- エラーを怖がらない
- 仮説を立てる
- 調べた内容を整理できる
- 質問が具体的
- 他人のコードを読む努力をする

伸びにくい人: 「答えを待つ」「動けばOK」「なぜ動くか説明できない」

## 1日1時間の授業設計

- 10分: 前回の復習・質疑応答
- 15分: 今日の新しい内容の解説
- 30分: 実際に手を動かす演習
- 5分: 振り返りと宿題

## 教師（メンター）に求める役割

1. **学習の道筋を作る**（最重要）— 迷わず進められるロードマップを示す
2. **エラー解決の考え方を教える** — エラーメッセージを読む → 原因を予想 → どこを調べるか → 仮説を検証
3. **コードレビュー** — 命名 / 可読性 / 重複 / 責務の分離 / バグになりそうな箇所
4. **モチベーション管理** — 1日1時間だと3日止まるだけで流れが切れる。小さな目標設定・できたことの確認・難しすぎる課題を出さない
5. **「なぜ？」を問いかける** — 「なぜこの書き方にした？」「他の方法は？」「もし100件データがあったら？」

教師に不要なこと: 文法を延々と講義する / スライドを読むだけ / 完成したコードを配る / すべて答えを教える（書籍・動画・AIで代替可能）

理想の教師像: 「講師」よりも**メンター兼コードレビュアー**。毎回のゴールを明確にし、学ぶ内容を整理 → 詰まったときの考え方を示す → コードレビューで改善点を伝える → 次回までの宿題を設定、のサイクルを回す。

## 学習ロードマップ（認証は対象外とする）

1. HTML
2. CSS
3. JavaScript
4. Git（clone / add / commit / push / pull だけで十分。branch や rebase は後回し）
5. TypeScript
6. React
7. Node.js（簡単なAPI）
8. SQL（DB）
9. ORM
10. デプロイ

- Git を TypeScript より前にする理由: 実際の開発では早い段階から Git を使う習慣をつけたほうが自然
- API と DB の順番: React で画面が作れるようになったあとに API → DB と学ぶと「API が DB との橋渡しをしている」と理解しやすい
- 最後はデプロイ: コードを書く → GitHub へ Push → 公開まで経験すると「自分でWebサービスを作った」実感が得られる
- 期間目安: 1日1時間・2人なら **4〜6か月程度**
